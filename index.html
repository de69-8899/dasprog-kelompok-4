Overview

Toolkit ini merupakan aplikasi berbasis bahasa C yang berjalan pada Command Line Interface (CLI). Program dirancang sebagai media pembelajaran untuk memahami konsep dasar pemrograman, perhitungan teknik, serta konversi sistem bilangan.

Fitur Utama

Kalkulator Hukum Ohm (V, I, R)
Desimal → Biner
Desimal → Oktal
Desimal → Heksadesimal
Biner → Desimal
Oktal → Desimal
Heksadesimal → Desimal

️ Cara Menjalankan

1. Kompilasi Program

gcc ver2-1.c -o toolkit

2. Jalankan Program

./toolkit
